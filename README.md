# SEYVEN_BEAUTY

Atelier Luxury Dermal E-Commerce Platform for SEYVEN.

## Monorepo Architecture
- **`frontend/`**: Next.js 16 Storefront (`theseyven.com`)
- **`admin-portal/`**: Next.js 16 Operations & Dispatch Desk (`admin.theseyven.com`)
- **`backend/`**: NestJS Dermal Engine & REST API (`api.theseyven.com`)
